# Truora SDK for Flutter (discontinued)

> ⚠️ **This package is discontinued on [pub.dev](https://pub.dev/packages/truora_sdk).**

`truora_sdk` has been replaced by **[flutter_validations_sdk](https://pub.dev/packages/flutter_validations_sdk)**, which provides native document and face validation, on-device liveness detection, and a richer integration surface for Flutter apps.

## Migrate to flutter_validations_sdk

```bash
flutter pub remove truora_sdk
flutter pub add flutter_validations_sdk
```

For the integration guide, see: <https://developer.truora.com/guides/validations_sdk_flutter/>

## What happens to existing integrations?

- The published `0.0.1` version remains installable; nothing has been removed from pub.dev.
- No further releases, fixes, or security patches will be published.
- Existing integrations will continue to build, but will not receive new features.
